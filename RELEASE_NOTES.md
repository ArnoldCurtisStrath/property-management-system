# Release notes

## Version 1.0

The first release of the Property Management System.

- Sign in and create an account.
- Add the properties that are rented out, with their type, rent and state.
- Add the tenants that live in them and keep their details.
- Record the rent that has been paid and see what is still outstanding.
- Raise maintenance requests and move them through their states.
- See the current weather at the address of a property.
- A daily background check that reminds about the rent that has not been paid.

The APK in this release is signed and can be installed on any phone that
runs Android 7 (API 24) or later.
